# Contributions

Contributions are very welcome — code, docs, whatever they might be. If this is
your first contribution to an Open Source project or you're a core maintainer
of multiple projects, your time and interest in contributing is most welcome.

If you're not sure where to get started, raise an issue in the project.

## More than 3 lines — talk to someone first

If you're planning on making a change that's more than 3 lines, please talk to
someone first so you don't waste time on something that might not be accepted.

## A PR should be one logical change

Please keep pull requests small and focused. If you have a big change, break it
into smaller, more manageable chunks.

## If you're not sure, ask!

Don't be afraid to ask for advice before working on a contribution. The preferred
ways to communicate are Discord or GitHub issues.
